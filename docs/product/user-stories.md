# User Stories — Hello Home

## US-1: Enter my name

As a user, I want to type my name on the Home screen, so that I can get a
personalized greeting.

## US-2: See my personalized greeting

As a user, who has entered my name and submitted it, I want to see a screen
that says "Hello, {name}!", so that I know the app recognized my input.

## US-3: Return to the Home screen

As a user viewing my greeting, I want to navigate back to the Home screen, so
that I can enter a different name or start over.

## US-4: Be prevented from submitting an empty name

As a user, I want the app to stop me from submitting a blank name, so that I
never see a broken or empty greeting.
